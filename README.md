## **Project Files and Their Functions**

### 1. `streamlit_example.py`
A demonstration of how to build a **Streamlit-based web application** for defect detection, providing an interactive interface for analyzing data with real-time visualizations.

### 2. `EWMA_filter.py`
An example implementation of an **Exponentially Weighted Moving Average (EWMA) filter**, used to explore filtering performance, smooth data fluctuations, and identify trends in time-series datasets.

### 3. `Dipole_data_analysis.py`
A script for **analyzing dipole datasets**, extracting meaningful insights, and visualizing results to better understand dipole behavior and trends.

### 4. `Resistor_network_Simulation.py`
A simulation tool for modeling **potential distributions in a 2D sheet**, featuring a defined-shaped object placed in the middle. This script allows flexible modifications of current, voltage, and sheet resistance for in-depth electrical analysis.
